# User Media Workflow v1

Status: `ACCEPTED`. Issue: #72. Authority: exact Product Owner instruction of
2026-09-11.

The native application copies and verifies a selected local audio/video file
into Integra-owned storage and starts a persistent local job. `ffmpeg`
normalizes audio and hash-bound `whisper-cli` processing produces timed machine
transcript evidence. Jobs expose durable state/progress and can be cancelled or
restarted from the owned source copy.

Deterministic grouping proposes Topics and Knowledge records. They remain
`REVIEW_REQUIRED` and `PROVISIONAL`; no ReviewDecision or semantic acceptance
is fabricated. Every record retains its source ID and exact media-time locator.
The workflow creates validated Obsidian and filesystem OneDrive packages for
the accepted preview/publication boundaries. No cloud verification is claimed.

Input files and SeminarText/VideoText repositories remain read-only. Private
data, credentials, live external publication, semantic acceptance, signing,
notarization, public release, and R14 acceptance remain outside authority.
