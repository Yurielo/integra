# Integra

Integra is the planned unified macOS application for knowledge, media,
learning, marketing, and publishing workflows built around the existing
SeminarText and VideoText systems.

The repository currently contains planning documentation only. Recording the
plan does **not** authorize implementation, source migration, deployment, data
access, or changes to SeminarText or VideoText.

The authoritative integration plan is:

- [`docs/INTEGRA_PLAN.md`](docs/INTEGRA_PLAN.md)
